Food Tracker Project

Welcome to the Food Tracker project! This is a modern web application for tracking food intake for yourself and your loved ones, built with Next.js, Tailwind CSS, and Firebase.

Getting Started

Follow these steps to set up and run the project:

Step 1: Make sure you have Node.js installed

This project requires Node.js version 16.8.0 or later. If you don't have it installed, download it from nodejs.org.

Step 2: Install dependencies and run the project

We've created several helper scripts to make it easier to install and run the project. Choose one of the following methods:

Option A: Using the Command File (Windows)

Double-click the install_and_run.cmd file in the project folder and follow the on-screen instructions.

Open Command File

Option B: Using PowerShell with Admin Rights

Right-click on run_as_admin.ps1 and select "Run with PowerShell". Follow the on-screen prompts.

Open PowerShell Script

Option C: Manual Installation

Open a command prompt or terminal in this directory and run:

npm install

After installation completes, run:

npm run dev

Step 3: View the application

After starting the development server, open your web browser and navigate to:

http://localhost:3000
Note about Firebase: This project uses a mock Firebase service for local development. In a production environment, you would need to set up a real Firebase project and update the configuration in services/firebase.ts.

Project Structure

The project is organized as follows:

  • /app: Next.js App Router pages and layouts
  • /components: Reusable React components
  • /services: API and Firebase services
  • /public: Static assets
