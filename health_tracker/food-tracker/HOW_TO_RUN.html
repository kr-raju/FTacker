Food Tracker - How to Run

This document provides instructions on how to run the Food Tracker application. This is a Next.js application that uses TypeScript, Tailwind CSS, and Firebase.

Prerequisites

  • Node.js (version 16.8.0 or later)
  • npm (included with Node.js)

Running the Application

Method 1: Using Batch Files (Windows)

  1. Setup the application:
    Double-click the setup.bat file in the project folder. This will install all the necessary dependencies.
  2. Start the development server:
    Double-click the run_dev.bat file in the project folder. This will start the development server.
  3. Access the application:
    Open your web browser and navigate to http://localhost:3000

Method 2: Using Command Line

  1. Open a command prompt or terminal
  2. Navigate to the project directory: 
    cd path/to/food-tracker
  3. Install dependencies (first time only): 
    npm install
  4. Start the development server: 
    npm run dev
  5. Access the application:
    Open your web browser and navigate to http://localhost:3000

Troubleshooting

Common Issues:

  • Security Restrictions:
    If you encounter security restrictions when running the batch files or npm commands, try running them as administrator.
  • Port Already in Use:
    If port 3000 is already in use, you might see an error. You can change the port by updating the package.json file and changing the dev script to: 
    "dev": "next dev -p 3001"
    (Replace 3001 with any available port)
  • Missing Dependencies:
    If you encounter errors about missing dependencies, try running: 
    npm install
    again to ensure all dependencies are properly installed.

Firebase Configuration

Before the application can fully function, you need to set up a Firebase project and update the configuration in services/firebase.ts with your own Firebase project details.
